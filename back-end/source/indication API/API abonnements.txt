## 1. Grille tarifaire

**`GET /api/abonnements/tarifs/`** — Public, pas de token requis  
Retourne uniquement les tarifs actifs (`est_actif = true`).

### Réponse `200 OK`

```json
{
  "success": true,
  "data": [
    { "id": "...", "plan": "basic",   "plan_label": "Basic",   "duree": "1_mois", "duree_label": "1 mois",  "prix": "9.99"  },
    { "id": "...", "plan": "basic",   "plan_label": "Basic",   "duree": "3_mois", "duree_label": "3 mois",  "prix": "24.99" },
    { "id": "...", "plan": "basic",   "plan_label": "Basic",   "duree": "6_mois", "duree_label": "6 mois",  "prix": "44.99" },
    { "id": "...", "plan": "premium", "plan_label": "Premium", "duree": "1_mois", "duree_label": "1 mois",  "prix": "19.99" },
    { "id": "...", "plan": "premium", "plan_label": "Premium", "duree": "3_mois", "duree_label": "3 mois",  "prix": "54.99" },
    { "id": "...", "plan": "premium", "plan_label": "Premium", "duree": "6_mois", "duree_label": "6 mois",  "prix": "99.99" }
  ]
}
```

> 💡 Utilise `plan_label` et `duree_label` directement dans l'interface — pas besoin de traduire les valeurs.

## 2. Souscrire à un abonnement

**`POST /api/abonnements/souscrire/`** — 🔒 Photographe requis

> ⚠️ Si le photographe a déjà un abonnement actif, il est automatiquement **annulé** avant la souscription du nouveau.

### Corps de la requête

```json
{
  "type":  "basic",
  "duree": "3_mois"
}
```

| Champ | Valeurs acceptées |
|---|---|
| `type` | `"basic"` \| `"premium"` |
| `duree` | `"1_mois"` \| `"3_mois"` \| `"6_mois"` |

### Réponse `201 Created`

```json
{
  "success": true,
  "message": "Abonnement souscrit avec succès.",
  "data": {
    "id": "...",
    "type": "basic",
    "duree": "3_mois",
    "status": "active",
    "prix": "24.99",
    "plan_tarif": {
      "id": "...",
      "plan": "basic",
      "plan_label": "Basic",
      "duree": "3_mois",
      "duree_label": "3 mois",
      "prix": "24.99"
    },
    "date_deb": "2024-11-15T10:30:00Z",
    "date_fin": "2025-02-13T10:30:00Z",
    "est_actif": true,
    "jours_restants": 90,
    "created_at": "2024-11-15T10:30:00Z"
  }
}
```

### Réponse erreur `400`

```json
{
  "success": false,
  "errors": { "type": ["\"gold\" is not a valid choice."] }
}
```

## 3. Vérifier son abonnement actif

**`GET /api/abonnements/statut/`** — 🔒 Photographe requis

> Met à jour automatiquement le statut si `date_fin` est dépassée.  
> À appeler au chargement du dashboard photographe.

### Réponse — abonnement actif `200 OK`

```json
{
  "success": true,
  "data": {
    "a_abonnement_actif": true,
    "abonnement": {
      "id": "...",
      "type": "premium",
      "duree": "6_mois",
      "status": "active",
      "prix": "99.99",
      "plan_tarif": { ... },
      "date_deb": "2024-11-15T10:30:00Z",
      "date_fin": "2025-05-14T10:30:00Z",
      "est_actif": true,
      "jours_restants": 180,
      "created_at": "2024-11-15T10:30:00Z"
    }
  }
}
```

### Réponse — aucun abonnement actif `200 OK`

```json
{
  "success": true,
  "data": {
    "a_abonnement_actif": false,
    "abonnement": null
  }
}
```

> 💡 Utilise `a_abonnement_actif` pour afficher ou masquer les fonctionnalités premium.

## 4. Annuler un abonnement

**`POST /api/abonnements/<uuid>/annuler/`** — 🔒 Photographe requis

### Corps de la requête

```json
{ "confirmation": true }
```

### Réponse `200 OK`

```json
{
  "success": true,
  "message": "Abonnement annulé.",
  "data": { "status": "annule", "est_actif": false, ... }
}
```

### Réponses erreur

```json
{ "success": false, "message": "Cet abonnement ne vous appartient pas." }
{ "success": false, "message": "Seul un abonnement actif peut être annulé." }
```

## Essai gratuit

> À l'inscription d'un compte **photographe**, un abonnement **Premium gratuit d'1 mois** est créé automatiquement. Aucune action requise côté frontend.

- Plan : `premium` — Prix : `0.00` — Durée : 30 jours
- Utilisable **une seule fois** par photographe
- Le champ `essai_utilise` dans `profil_photographe` indique si l'essai a déjà été utilisé

```json
{ "profil_photographe": { "essai_utilise": true } }
```

> 💡 Utilise `essai_utilise` pour afficher/masquer un badge "Essai gratuit disponible" sur la page de tarification.

## Suivi (Follow / Unfollow)

### Toggle follow/unfollow

**`POST /api/abonnements/suivre/<uuid>/`** — 🔒 Authentifié requis

Aucun corps requis. Toggle : si déjà suivi → unfollow, sinon → follow.

### Réponse `200 OK`

```json
{
  "success": true,
  "data": {
    "suivi": true,
    "nombre_abonnes": 42
  }
}
```

### Réponse erreur `400`

```json
{ "success": false, "message": "Vous ne pouvez pas vous suivre vous-même." }
```

## Admin — CRUD Plans tarifaires

> 🔒 **Rôle `admin` requis sur tous ces endpoints.** Retourne `403` pour tout autre rôle.

### Liste et création

**`GET /api/abonnements/admin/tarifs/`** — Retourne TOUS les tarifs (actifs et inactifs)

```json
{
  "success": true,
  "data": [
    {
      "id": "...",
      "plan": "basic",
      "plan_label": "Basic",
      "duree": "1_mois",
      "duree_label": "1 mois",
      "prix": "9.99",
      "est_actif": true,
      "created_at": "2024-11-15T10:30:00Z",
      "updated_at": "2024-11-15T10:30:00Z"
    }
  ]
}
```

**`POST /api/abonnements/admin/tarifs/`** — Créer un tarif

```json
{
  "plan":      "basic",
  "duree":     "1_mois",
  "prix":      9.99,
  "est_actif": true
}
```

| Champ | Requis | Valeurs |
|---|---|---|
| `plan` | ✅ | `"basic"` \| `"premium"` |
| `duree` | ✅ | `"1_mois"` \| `"3_mois"` \| `"6_mois"` |
| `prix` | ✅ | Nombre décimal > 0 |
| `est_actif` | ❌ | `true` par défaut |

### Réponse erreur — doublon `400`

```json
{
  "success": false,
  "errors": { "non_field_errors": ["Un tarif 'basic — 1_mois' existe déjà."] }
}
```

---

### Détail, modification et suppression

**`GET /api/abonnements/admin/tarifs/<uuid>/`** — Détail d'un tarif

**`PATCH /api/abonnements/admin/tarifs/<uuid>/`** — Modifier (tous les champs optionnels)

```json
{ "prix": 12.99 }
```
ou
```json
{ "est_actif": false }
```

**`DELETE /api/abonnements/admin/tarifs/<uuid>/`** — Supprimer

> ⚠️ La suppression est **bloquée** si des abonnements actifs utilisent ce tarif :
> ```json
> {
>   "success": false,
>   "message": "2 abonnement(s) actif(s) utilisent ce tarif. Désactivez-le plutôt que de le supprimer."
> }
> ```
> Dans ce cas, utilise `PATCH` avec `{ "est_actif": false }` pour désactiver sans supprimer.

### Réponse suppression `200 OK`

```json
{ "success": true, "message": "Plan tarifaire supprimé." }
```

## Structure des objets

```typescript
interface PlanTarif {
  id: string;
  plan: "basic" | "premium";
  plan_label: string;         // "Basic" | "Premium"
  duree: "1_mois" | "3_mois" | "6_mois";
  duree_label: string;        // "1 mois" | "3 mois" | "6 mois"
  prix: string;               // Décimal ex: "9.99"
  est_actif?: boolean;        // Présent uniquement sur les endpoints admin
  created_at?: string;        // Présent uniquement sur les endpoints admin
  updated_at?: string;        // Présent uniquement sur les endpoints admin
}

interface Abonnement {
  id: string;
  type: "basic" | "premium";
  duree: "1_mois" | "3_mois" | "6_mois";
  status: "active" | "expire" | "annule";
  prix: string;
  plan_tarif: PlanTarif | null;
  date_deb: string;
  date_fin: string;
  est_actif: boolean;
  jours_restants: number;
  created_at: string;
}

interface StatutSuivi {
  suivi: boolean;
  nombre_abonnes: number;
}
```
